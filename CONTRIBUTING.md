# Contributing

Thanks for contributing to Sales Page Builder.

## Before you start

1. Check existing issues and pull requests to avoid duplicate work.
2. For larger changes, open an issue first and describe the proposed approach.
3. Read the repository README and follow the existing TypeScript/React patterns.

## Development

```bash
npm install
npm run dev
npm run lint
npm run build
```

## Pull requests

- Keep each PR focused on one problem.
- Include tests when changing behavior.
- Update documentation when public behavior or APIs change.
- Do not commit secrets, credentials, generated build output, or unrelated formatting changes.
- Explain what changed, why it changed, and how it was verified.

## Good first contributions

Documentation, accessibility fixes, tests, small UI bugs, type-safety improvements, and isolated components are especially useful starting points.
